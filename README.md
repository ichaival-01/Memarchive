# Mem-archive
An old archive of a video game I made of a project in grade 12 involving basic Java application and the NETBEANS IDE.

The general focus of this repository was to act as a proper "archive" or space for me to store this project and its (mangled) entirety. It involved a lot of tricky application with Java GUI functions, Variables, Booleans and Object-Oriented Programming (OOP) philosophy.

While the project has, for better or for worse, been left-to-rot, It still functions when decompiled and recompiled; a miracle of modern technology.

Since the actual assets of the project seem to be too big to actually store ON github, I'll probably make a link accessible to download whatever's in the project so its easier to look at.

What's compiled here is just the program code itself.
